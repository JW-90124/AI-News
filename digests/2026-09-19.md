## 5. stagehand-python@4.2.0a0.dev1524: [feat]: add WebMCP tools added/removed event hooks (#2916)

- **事实**：Stagehand 发布 stagehand-python@4.2.0a0.dev1524，新增 WebMCP 工具添加/移除事件钩子（#2916）。该 PR 在 TypeScript 中新增 onToolsAdded()/onToolsRemoved()，Python 中新增 on_tools_added()/on_tools_removed()，Go 中新增 OnToolsAdded()/OnToolsRemoved()。由于 WebMCP.enable 会让 Chrome 对已存在的工具重复发出 toolsAdded 事件，PR 引入工具注册表来管理已添加/移除状态，page.tools() 改为读取该注册表而非再次启用 WebMCP。代码还涉及跨导航与 iframe 分离时的状态同步，复用已有订阅句柄实现 unsubscribe()/Close(ctx)，在原始 page.cdp_event 路径之外新增类型化 page.event 通知，并共享协议 schema 与生成的 SDK 模型，同时将订阅建立改为异步并处理注册失败或订阅者断开时的清理。
- **技术视角**：该改动把 WebMCP 工具生命周期从隐式副作用转为可订阅事件，并用注册表替代重复启用，属于浏览器 Agent 工具状态管理的基础设施修补。可验证下一信号：后续版本是否公开注册表查询接口或事件语义文档，以及 page.tools() 行为是否在跨导航场景下保持稳定。
