## 6. b11243

- **事实**：llama.cpp 发布 b11243，将 CI 更新至 oneAPI 2026.1。证据称 oneDNN 在 Intel Deep Learning Essentials 2026.0 中被移除，因此继续使用 deep-learning-essentials 路径会在工具包版本更新时静默失去 oneDNN 支持；改动将 Ubuntu 与 Windows CI 任务切换到新的统一 Intel oneAPI Toolkit 安装器，该安装器仍包含 oneDNN（至 2027.0），并保持 Windows 安装脚本的组件 ID 不变。证据还称，在 Arc B570 上用同一代码（b10899）分别以 oneAPI 2026.1 与基于 2025.3 的发布构建测量：prompt processing 为 1331 对 434 t/s（3.1x），token generation 为 50.1 对 45.3-48.0 t/s。同时更新了 SYCL 后端构建要求文档（2026.0 起 Base 与 HPC 工具包合并为 oneAPI Toolkit，oneDNN 从 Deep Learning Essentials 移除），并更新了发布工作流以适配 oneAPI 2026.1 与 Level Zero SDK 1.33.1。
- **技术视角**：证据将性能差异归因于 oneAPI 2026.1 与 2025.3 构建的对比，但未说明具体优化来源，因此 3.1x 的 prompt processing 提升是否可稳定复现仍需独立验证。可验证下一信号：后续 llama.cpp 发布说明或基准中是否出现相同 Arc B570 配置下的重复测量，以及 oneDNN 在 2027.0 之后是否仍被保留。
- **行业影响**：该改动反映 Intel 工具链打包策略变化（Base 与 HPC 合并、oneDNN 移出 Deep Learning Essentials）对开源推理项目构建路径的直接影响。可验证下一信号：其他依赖 oneDNN 的开源项目是否同步迁移安装器，以及 Intel 是否发布 oneDNN 在 2027.0 后的替代或延续说明。
