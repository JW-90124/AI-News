## 7. v0.32.10-rc0: nn: speed up prefill on double-scale nvfp4 models

- **事实**：Ollama 发布 v0.32.10-rc0，针对 double-scale nvfp4 模型优化 prefill 速度。ModelOpt checkpoints 在每个投影输出上应用 float32 全局缩放，加上每组的量化缩放。将乘法和转换回激活 dtype 的操作编译为单个内核，减少内核启动和中间物化。在 M5 Max 上，qwen3.6:27b prefill 从 703 提升到 769 t/s（+7.9%），muse-glimmer:30b prefill 从 790 提升到 843 t/s（+6.7%）。投机解码在噪声范围内不变。仅影响带全局缩放的检查点；单尺度 nvfp4、mxfp8 和 affine 检查点走未改变路径。
- **技术视角**：该优化针对 ModelOpt 检查点的全局缩放模式，通过内核融合减少内核启动和中间张量，提升 prefill 吞吐。可验证的下一信号：在更多模型和硬件上测试该优化是否普遍适用，或观察是否扩展到其他量化格式。
- **行业影响**：Ollama 持续优化推理性能，特别是针对特定量化格式，表明开源推理引擎在竞争性能优势。可验证的下一信号：其他推理引擎是否跟进类似优化，或 Ollama 是否在后续版本中扩展支持。
- **值得关注**：该优化可能降低 double-scale nvfp4 模型的推理成本，促进其采用。可验证的下一信号：观察该优化是否被合并到稳定版本，并跟踪相关模型的使用率变化。
- 证据：[v0.32.10-rc0: nn: speed up prefill on double-scale nvfp4 models](https://github.com/ollama/ollama/releases/tag/v0.32.10-rc0)

## 8. Pay with confidence: How Solv Labs built verifiable, auditable agent payments on Amazon Bedrock AgentCore payments

- **事实**：Solv Labs 在 Amazon Bedrock AgentCore payments 上构建了一个受治理的 Agent 支付工作流，每笔交易在结算前都经过授权、在 AWS Nitro Enclave 中证明、按风险定价并锚定到公共区块链。该模式为企业提供了在受监管环境中自主 Agent 支付的可验证、可审计的追踪记录。
- **技术视角**：该工作流结合了授权、Nitro Enclave 证明、风险定价和区块链锚定，可能为 Agent 支付提供端到端的可审计性。下一步可验证的信号是：是否有更多企业采用该模式，以及该模式是否被标准化为 Agent 支付的基础设施。
- **行业影响**：该案例表明，在受监管环境中，Agent 支付的可验证性和可审计性正成为企业采用的关键考量。下一步可验证的信号是：是否有更多云服务商或支付平台推出类似的 Agent 支付解决方案。
