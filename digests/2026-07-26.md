## 1. ONNX Runtime v1.28.0

- **事实**：ONNX Runtime v1.28.0 发布，升级到 ONNX 1.22.0 和 protobuf 6.33.5，cuDNN 和 cuFFT 在 CUDA EP 中变为运行时可选，引入实验性 C/C++ API，移除 TensorRT fused causal attention kernels 等。
- **技术视角**：该版本通过使 cuDNN 和 cuFFT 可选，显著减少了 CUDA 运行时依赖，可能降低部署门槛。实验性 C/C++ API 的引入为更底层的集成提供了可能。
- **行业影响**：ONNX Runtime 作为跨平台推理引擎，其依赖精简和 API 扩展有助于提升在边缘设备和异构环境中的适用性，可能推动 ONNX 生态的进一步采用。
- **值得关注**：后续可关注实验性 C/C++ API 的稳定化以及 cuDNN 可选后对性能的影响。
- 证据：[ONNX Runtime v1.28.0](https://github.com/microsoft/onnxruntime/releases/tag/v1.28.0)
