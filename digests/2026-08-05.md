## 1. @ai-sdk/black-forest-labs@2.0.22

- **事实**：Vercel AI SDK 发布 @ai-sdk/black-forest-labs@2.0.22 和 @ai-sdk/black-forest-labs@1.0.51 补丁，修复 FLUX 3 视频生成中 settled cost 未报告的问题。提交响应只能估算成本，当价格取决于完成视频时返回无成本；结果端点返回 SettledCostResultResponse，但其成本此前被丢弃。
- **技术视角**：该补丁修复了成本报告链路，确保结果端点返回的 SettledCostResultResponse 中的成本被正确报告，而非被丢弃。
- **行业影响**：此修复表明视频生成服务的成本计算可能依赖完成视频的属性，导致提交时无法准确估算，需要结果端点提供最终成本。
- **值得关注**：未来视频生成 API 可能更普遍地采用结果端点报告最终成本，以提供准确的计费信息。
- 证据：[@ai-sdk/black-forest-labs@2.0.22](https://github.com/vercel/ai/releases/tag/%40ai-sdk%2Fblack-forest-labs%402.0.22)
- 证据：[@ai-sdk/black-forest-labs@1.0.51](https://github.com/vercel/ai/releases/tag/%40ai-sdk%2Fblack-forest-labs%401.0.51)

## 5. TensorRT 11.2 Release

- **事实**：NVIDIA 于 2026-08-04 发布 TensorRT 11.2。新增 Python 示例 sample_plugin_v2_to_v3_migration，演示从 IPluginV2 迁移到 IPluginV3。新增 FFTPlugin，基于 cuFFT，支持复数到复数、实数到复数、复数到实数变换，以支持 ONNX DFT 算子。解析器新增 IRefitterObserver 类，用于更好地重构 ONNX 模型。新增对 DFT 算子和 5D GridSample 算子的支持。
- **技术视角**：TensorRT 11.2 通过新增 cuFFT 后端插件和 IRefitterObserver，强化了 ONNX 算子覆盖与模型重构能力，可能提升复杂模型（如涉及频域变换）的推理效率与精度。
- **行业影响**：该版本聚焦 ONNX 生态兼容性，表明 NVIDIA 正巩固其在 AI 推理基础设施中的主导地位，并响应开发者对更广泛算子支持的需求。
- **值得关注**：后续可观察 TensorRT 对更多 ONNX 算子（如动态形状、注意力变体）的支持，以及 IRefitterObserver 在真实部署中的采用率。
- 证据：[TensorRT 11.2 Release](https://github.com/NVIDIA/TensorRT/releases/tag/v11.2)
